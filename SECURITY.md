# Security Policy

## Supported Versions

The default branch receives security fixes for the current local-first Chrome extension and local server.

## Reporting A Vulnerability

Please report suspected security issues through GitHub Security Advisories when available. If private vulnerability reporting is not enabled, open a GitHub issue with only a high-level description and do not include secrets, API keys, OAuth tokens, cookies, private images, or local run data.

## Sensitive Data

Do not publish `.env` files, Provider API keys, OAuth tokens, cookies, local browser profiles, `runs/` data, generated portraits, or personal screenshots. The project is designed for local use, and user images and Provider credentials should remain on the user's machine.
